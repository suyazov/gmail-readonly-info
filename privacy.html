Политика конфиденциальности

Эта политика описывает обработку данных приложением Codex Gmail Readonly — личным инструментом доступа к Gmail только для чтения.

Какие данные обрабатываются

Приложение проверяет адрес подключённого аккаунта и обрабатывает идентификаторы писем, отправителей, темы и даты. По прямой инструкции владельца оно может читать содержимое выбранных писем и извлекать домены ссылок. Для сохранения подключения используются OAuth access token и refresh token.

Цель обработки

Данные используются исключительно для поиска, чтения и анализа почты в рамках поручений владельца аккаунта. Приложение не продаёт данные Gmail и не использует их для рекламы. В коде инструмента нет функций обучения моделей машинного обучения.

Где выполняется обработка

Инструмент запускается на компьютере оператора, его сервере либо в выбранной им облачной рабочей среде. При использовании Codex данные, необходимые для выполнения поручения, могут обрабатываться платформой Codex/OpenAI. Это не даёт приложению права передавать почту произвольным третьим лицам; оператор обязан соблюдать Google API Services User Data Policy и настройки конфиденциальности выбранной платформы.

Хранение и защита

OAuth-файлы хранятся вне Git и публичного каталога сайта; на поддерживаемой Unix-системе каталог имеет права 0700, файлы — 0600. Токены не должны попадать в сообщения, логи и общие документы. Почтовые выгрузки и рабочие результаты сохраняются только по поручению владельца; их место и срок хранения определяются его рабочим проектом. Сам почтовый ящик Gmail инструмент не изменяет.

Контроль владельца

Владелец может прекратить использование инструмента и отозвать доступ в Google. Удаление локального файла токена само по себе не отзывает доступ Google. После отзыва оператор удаляет сохранённые файлы доступа и ненужные рабочие выгрузки; копии в рабочей платформе удаляются её штатными средствами и по её правилам хранения.

Правила Google

Использование и передача информации, полученной через Google APIs, должны соответствовать Google API Services User Data Policy, включая требования Limited Use. Данные Gmail нельзя использовать для обучения универсальных моделей ИИ. Ограничение действует и при выборе облачной среды.

Обращения

По вопросам обработки данных следует обращаться к оператору по контакту поддержки, указанному на экране OAuth-согласия Google. Изменения фактического способа обработки требуют обновления этой политики и соответствующего согласия владельца.
